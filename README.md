Tool Belt
=============

A belt to carry your tools in.


=============

ToolBelt-Plus is a fork of [gigaherz/ToolBelt](https://github.com/gigaherz/ToolBelt) for **Minecraft 1.21.1 / NeoForge** that lets the tool belt grow past 9 slots.

## Features
- Belts can be upgraded up to **36 slots**: 4 radial wheels of 9.
- **Scroll the mouse wheel** while the radial menu is open to switch wheels. Dots and "Wheel X/4" under the menu show which wheel you're on, and the menu reopens on the last wheel you used.
- **Each wheel is a fixed set of 9 slots** (wheel 1 = slots 1–9, wheel 2 = 10–18, and so on), so items on one wheel never shift onto another. Empty slots are hidden per wheel unless `displayEmptySlots` is enabled.
- **INSERT** puts the held item into the first empty slot of the wheel you're looking at.
- The belt inventory screen shows slots in rows of 9, and each row matches a wheel.
- Upgrades past 9 slots work in the anvil (30 levels each), in JEI, and with Sewing Kit (netherite needle).

## Install
Replace the original ToolBelt jar with `ToolBelt-1.21.1-2.2.10-plus0.2.jar`. On a server, the server and every player need this jar.
